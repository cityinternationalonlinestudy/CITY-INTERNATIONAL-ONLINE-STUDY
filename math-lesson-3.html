1. What is Algebra?

Algebra is a branch of Mathematics that uses letters and symbols together with numbers to represent unknown or changing quantities.

Example:
x + 5
Here, x represents a number that we may not know yet.

Algebra helps us solve problems where an unknown value needs to be found.

2. Variables

A variable is a letter or symbol used to represent a value that can change or is unknown.

x

A common variable.

y

Another common variable.

a

Can also represent an unknown value.

Example: If:
x = 5
then the value of x is 5.

3. Constants

A constant is a number whose value does not change.

In the expression:
x + 7
x is the variable.

7 is the constant.

4. Algebraic Expressions

An algebraic expression is made using numbers, variables and mathematical operations.

x + 5

Addition expression

y - 3

Subtraction expression

2x

Multiplication expression

x ÷ 4

Division expression

5. Terms

A term is a number, variable or product of numbers and variables.

Consider:
3x + 5
There are two terms:

3x
and
5

6. Like Terms

Like terms contain the same variable raised to the same power.

Like terms:
3x and 5x
They can be combined.
Unlike terms:
3x and 5y
They cannot be combined directly because they have different variables.

7. Simplifying Expressions

To simplify an expression, combine like terms.

Example:
3x + 2x
Add the coefficients:

3 + 2 = 5

Therefore:
3x + 2x = 5x

8. Simple Equations

An equation states that two expressions are equal.

Example:
x + 3 = 8
We want to find x.

Subtract 3 from both sides:
x = 8 - 3
Therefore:
x = 5

9. Another Equation Example

Solve:
x - 4 = 10
Add 4 to both sides:
x = 10 + 4
Therefore:
x = 14
